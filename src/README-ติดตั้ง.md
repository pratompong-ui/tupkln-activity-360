# ติดตั้ง PWA ให้ TUPKLN ACTIVITY 360

ทำให้ครูกด "เพิ่มลงหน้าจอโฮม" แล้วเปิดใช้เหมือนแอปจริง ไม่มีแถบเบราว์เซอร์ มีไอคอนน้อง CARE บนหน้าจอ

## ไฟล์ที่ต้องอัปโหลดขึ้น GitHub

วางตามตำแหน่งนี้ในรีโป `tupkln-activity-360`

| ไฟล์ | ตำแหน่งในรีโป | การทำงาน |
|---|---|---|
| `manifest.webmanifest` | `public/manifest.webmanifest` | บอกมือถือว่าแอปชื่ออะไร ใช้ไอคอนไหน เปิดแบบเต็มจอ |
| `sw.js` | `public/sw.js` | ทำให้เปิดได้แม้สัญญาณขาดช่วง |
| `icon-192.png` | `public/icon-192.png` | ไอคอนแอนดรอยด์ |
| `icon-512.png` | `public/icon-512.png` | ไอคอนความละเอียดสูง |
| `icon-maskable-512.png` | `public/icon-maskable-512.png` | ไอคอนทรงกลม/ทรงหยดน้ำของแอนดรอยด์ |
| `apple-touch-icon.png` | `public/apple-touch-icon.png` | ไอคอน iPhone และ iPad |
| `icon.svg` | `public/icon.svg` | ไอคอนบนแท็บเบราว์เซอร์ |
| `index.html` | `index.html` (ราก ไม่ใช่ใน public) | วางทับของเดิม |
| `main.jsx` | `src/main.jsx` | วางทับของเดิม |

## วิธีอัปโหลดทาง GitHub

1. เปิดรีโป กด **Add file → Upload files**
2. ลากไฟล์ทั้ง 7 ไฟล์ลงไป แล้วพิมพ์ชื่อโฟลเดอร์ `public/` นำหน้าเมื่อระบบถาม หรือเข้าไปในโฟลเดอร์ `public` ก่อนแล้วค่อยอัปโหลด
3. `index.html` กับ `src/main.jsx` ใช้วิธีเปิดไฟล์เดิม กดดินสอ เลือกทั้งหมด แล้ววางทับ
4. กด **Commit changes** แล้วรอ Vercel build ประมาณ 1–2 นาที

## วิธีให้ครูติดตั้ง

**แอนดรอยด์ (Chrome)** เปิดลิงก์ → จะมีแถบ "ติดตั้งแอป" เด้งขึ้นมา หรือกดจุดสามจุดมุมขวาบน → เพิ่มลงในหน้าจอหลัก

**iPhone (Safari เท่านั้น)** เปิดลิงก์ใน Safari → กดปุ่มแชร์ด้านล่าง → เลื่อนหา "เพิ่มไปยังหน้าจอโฮม" → กดเพิ่ม

> iPhone ติดตั้งผ่าน Chrome หรือผ่านเบราว์เซอร์ในแอปไลน์ไม่ได้ ถ้าครูเปิดลิงก์จากไลน์ ให้กดจุดสามจุดมุมขวาบนแล้วเลือกเปิดใน Safari ก่อน

## ข้อควรรู้

- ต้องเป็น https เท่านั้น ซึ่ง Vercel ให้อยู่แล้ว
- เวลาท่านอัปเดตโค้ดใหม่ ครูจะได้เวอร์ชันล่าสุดอัตโนมัติเมื่อเปิดแอปครั้งถัดไป เพราะตั้งค่าให้ดึงจากเครือข่ายก่อนเสมอ
- ข้อมูลจาก Supabase ไม่ถูกเก็บลงแคช จึงไม่มีปัญหาเห็นข้อมูลเก่าค้าง
- ถ้าออฟไลน์ ครูจะยังเปิดแอปได้แต่เห็นข้อมูลเท่าที่โหลดไว้ล่าสุด
